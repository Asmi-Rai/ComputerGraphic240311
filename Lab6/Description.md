**Creating Two Dimensional Objects**

Two dimensional objects can be created in C-language by using graphics functions such as line(), circle(), ellipse(), rectangle(), and drawpoly(). These functions help in drawing basic geometric shapes by activating the required pixels on the screen. By combining these basic shapes, complex 2D objects can be formed.

For example, a house can be created by drawing a rectangle for the main building, a triangle using drawpoly() for the roof, and small rectangles for doors and windows.

A car can be formed using rectangles for the body and circles for the wheels.

A fish can be created using an ellipse for the body, a triangle for the tail, and a small circle for the eye.

A man can be drawn using a circle for the head and lines for hands, legs, and body.

Thus, by properly combining lines, circles, ellipses, rectangles, and polygons, different simple two dimensional objects can be created in C graphics. These functions internally generate pixel positions and activate them to display the desired shapes on the screen.
